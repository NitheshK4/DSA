## ⚙️ Automated Sync Workflow

This repository automatically syncs and categorizes new solutions using a custom GitHub Actions workflow and metadata parser.

### 🔄 How It Works
1. **Submit**: Solve problems on [LeetCode](https://leetcode.com/u/Nithesh_007/).
2. **Push**: LeetHub / Chrome Extension commits the solution to this repository.
3. **Sync Action**: GitHub Actions automatically runs `scripts/sync_readme.py` on push to:
   - Categorize new solutions into appropriate algorithmic topics.
   - Query LeetCode's GraphQL API for real-time problem numbers, difficulty, and tags.
   - Refresh profile statistics and update this `README.md` seamlessly.

### 🛠️ Manual Synchronization
You can also run the sync script locally at any time:
```bash
# Run sync script
python3 scripts/sync_readme.py
```
